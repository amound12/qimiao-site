# 架构说明

> 奇妙小站 v0.1.0 · 技术栈：FastAPI + Jinja2 + SQLite · 部署：Docker Compose + Nginx

## 一、设计哲学

**乐高式模块化**：核心（core/）是底板，每个功能是一块积木（modules/<name>/）。
积木可以随时装上、拆下、扔掉，底板和其他积木毫发无损。

三条铁律：
1. 新增功能 = 新建模块目录 + `.env` 登记一行，**永不修改 core/**
2. 模块之间禁止互相 import 内部实现，只通过 `core.registry` 的 MODULE 清单交流
3. 每个模块自带路由、页面、配置、数据库、静态资源，删目录即删功能

## 二、目录结构

```
qimiao/
├── main.py                  # 总入口：建 app → 装配模块 → 启动（新增功能永不修改）
├── core/                    # ★ 底板：新增功能时永远不动这里
│   ├── config.py            #   读 .env：站点信息 + MODULES_ENABLED + DATA_DIR
│   ├── registry.py          #   模块注册中心（本项目的灵魂）
│   ├── render.py            #   全局模板渲染：导航/站点信息自动注入
│   ├── database.py          #   SQLite 工具：每模块独立 .db 文件
│   ├── pages.py             #   首页/关于页路由（核心页面，永远在线）
│   ├── templates/           #   base.html / home / about / 404
│   └── static/              #   site.css（全站设计令牌）+ site.js + 头像 + fonts/（自托管字体）
├── modules/                 # ★ 乐高区：一块模块 = 一个目录
│   ├── todo/                #   示例模块「每日待办」（新模块开发模板）
│   │   ├── __init__.py      #     MODULE 清单 + get_router() + setup()
│   │   ├── router.py        #     页面路由 + JSON 接口
│   │   ├── models.py        #     数据层（独立 todo.db）
│   │   ├── templates/todo/  #     模块页面（extends base.html）
│   │   └── static/          #     模块私有 CSS/JS（挂载在 /static/modules/todo/）
│   └── _template/           #   空白脚手架（新功能从这里复制起步）
├── deploy/                  # Dockerfile、docker-compose.yml、nginx 配置
├── scripts/                 # backup.sh（备份）、rollback.sh（一键回滚）
├── tests/                   # 自动化测试（pytest）
├── .github/workflows/       # CI：push 自动跑测试 + 构建 Docker 镜像
├── docs/                    # 你正在看的这套文档
├── .env.example             # 配置模板（真实 .env 不入 Git）
└── requirements.txt
```

## 三、模块注册机制（核心）

启动流程一句话：`main.py` 读 `.env` → `Registry` 逐个导入 `MODULES_ENABLED` 里的模块
→ 收集每个模块的 `MODULE` 清单 → 挂载静态资源与路由 → 初始化合并模板环境。

```
.env (MODULES_ENABLED=todo)
        │
        ▼
   main.py ──► core/registry.py ──► 装配到 FastAPI app
        │                              ├── 导航项      → base.html 动态渲染
        │                              ├── 首页卡片    → home.html 实验室区自动生成
        │                              ├── 路由挂载    → app.include_router(prefix)
        │                              └── 静态资源    → /static/modules/<name>/
        ▼
  modules/todo/ 等模块目录（互相独立，互不感知）
```

### ModuleManifest 字段速查

| 字段 | 作用 | 例 |
|---|---|---|
| `name` | 模块标识（=目录名） | `"todo"` |
| `title` | 显示名（导航/卡片） | `"每日待办"` |
| `prefix` | 路由前缀 | `"/todo"` |
| `description` | 首页卡片一句话介绍 | `"今天的事今天管"` |
| `version` | 模块自己的版本号 | `"0.1.0"` |
| `nav_label` | 顶部导航文字，留空不进导航 | `"待办"` |
| `nav_order` | 导航排序（小在前） | `10` |
| `card_badge` | 首页卡片徽章 | `"v0.1 · 上线"` |
| `show_on_home` | 是否上首页卡片墙 | `True` |

### 模块的三个对外接口

```python
MODULE = ModuleManifest(...)      # 必需：模块清单
def get_router(): ...             # 必需：返回 APIRouter
def setup(): ...                  # 可选：初始化（建表/迁移），启用时自动执行
```

### 容错

单个模块导入或初始化失败 → 只记日志并跳过，整站与其他模块照常运行。

## 四、数据隔离

- 每个模块一个独立 SQLite 文件，统一放在 `DATA_DIR`（生产环境 = Docker 挂载的 `./data`）
- 用法：`with connect("todo.db") as conn: conn.execute(...)`
- 删除/禁用模块不影响其他模块数据；彻底删除模块 = 删目录 + 删对应 db 文件

## 五、如何新增一个模块（三步）

```bash
# 1. 复制脚手架并改名
cp -r modules/_template modules/my_module

# 2. 修改 modules/my_module/__init__.py 里的 MODULE 清单（name/prefix/title 等）

# 3. 在 .env 登记（逗号分隔，可多模块）
#    MODULES_ENABLED=todo,my_module
```

重启（本地重启 uvicorn / 服务器 `docker compose -f deploy/docker-compose.yml restart`），
导航项、首页卡片、路由全部自动出现。详细流程见《新功能开发SOP.md》。

## 六、如何禁用 / 删除模块

```bash
# 禁用：.env 里删掉模块名
MODULES_ENABLED=            # 留空 = 只有首页/关于/404

# 删除：禁用后直接删目录（可选：连 data/<模块>.db 一起删，数据无残留）
rm -rf modules/todo
```

禁用效果：导航项消失、首页卡片消失、`/todo` 返回 404，其余一切正常（有自动化测试兜底：`tests/test_app.py::test_disabled_module`）。

## 七、设计令牌

全站视觉统一由 `core/static/site.css` 顶部的 CSS 变量控制（提取自设计模板）：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--paper` | #FBFAF7 | 画布底色（暖纸感） |
| `--ink` | #26231F | 主文字（墨色） |
| `--accent` | #FF6B4A | 点缀色（珊瑚橙） |
| `--accent-dark` | #C2492F | 徽章文字 |
| `--accent-soft/tint/back` | #FFE8E0 / #FFF3EE / #FFD9CC | 点缀色渐层底 |
| `--star-yellow` | #FFC53D | 装饰星星 |
| `--radius-card/page/pill` | 36 / 24 / 999px | 圆角体系 |
| `--font-sans/fun/hand` | Noto Sans SC / ZCOOL KuaiLe / Caveat | 字体体系（已自托管在 `core/static/fonts/`，不依赖 Google Fonts） |

改全站配色只动这一处；模块私有样式只允许**使用**令牌，不允许定义全局规则。
