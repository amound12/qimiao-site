# 部署手册

> 面向「会用 SSH 但不精通运维」的你。从零到上线，照抄命令即可。
> 假设：云服务器为 Alibaba Cloud Linux 3 / alinux3（1核1G 起步即可），你有一个 GitHub 仓库。
> 每一步都注明了「这步在做什么」。带 ⚠️ 的命令有风险，先看说明再执行。

---

## 第 0 步：准备清单

- [ ] 一台云服务器（Alibaba Cloud Linux 3 / alinux3，至少 1核1G，磁盘 20G+）
- [ ] 能用 SSH 登录服务器（`ssh root@服务器IP`）
- [ ] （可选）一个域名，解析 A 记录到服务器 IP —— 没有也能部署，用 IP 访问，跳过第 7 步
- [ ] 代码已推送到 GitHub 仓库（假设地址为 `https://github.com/你的用户名/qimiao.git`，下面记得替换）

---

## 第 1 步：服务器初始化

SSH 登录后，先更新系统并设置时区（做什么：装安全补丁、把时钟调成北京时间）：

```bash
dnf update -y
timedatectl set-timezone Asia/Shanghai
```

配置防火墙（做什么：只放行 SSH(22)、HTTP(80)、HTTPS(443) 三个端口，其余全关）：

> ⚠️ 危险点说明：`firewall-cmd --add-service=ssh` 必须在 `--add-service=ssh --permanent`
> 之后执行 reload，否则可能把自己锁在服务器外面。

```bash
dnf install -y firewalld
systemctl enable --now firewalld
firewall-cmd --permanent --add-service=ssh
firewall-cmd --permanent --add-service=http
firewall-cmd --permanent --add-service=https
firewall-cmd --reload
firewall-cmd --list-all
```

## 第 2 步：安装 Docker

（做什么：安装 Docker 引擎和 compose 插件，我们的站点跑在容器里）

```bash
curl -fsSL https://get.docker.com | sh
systemctl enable --now docker
docker --version && docker compose version
```

> 如果 `curl` 那步网络超时：`dnf install -y docker docker-compose-plugin` 也可以，版本稍旧但够用。

验证（做什么：跑个最小容器确认 Docker 正常，跑完自动删掉）：

```bash
docker run --rm hello-world
```

## 第 3 步：拉取代码

（做什么：把仓库克隆到 `/opt/qimiao`，以后所有操作都在这个目录）

```bash
dnf install -y git
git clone https://github.com/你的用户名/qimiao.git /opt/qimiao
cd /opt/qimiao
```

> GitHub 连不上/太慢的备选方案：在本地电脑打包后上传（在**本地**执行）：
> ```bash
> git archive --format=tar.gz -o qimiao.tar.gz HEAD
> scp qimiao.tar.gz root@服务器IP:/opt/
> ```
> 然后在**服务器**上：`mkdir -p /opt/qimiao && tar -xzf /opt/qimiao.tar.gz -C /opt/qimiao && cd /opt/qimiao`

## 第 4 步：配置 .env

（做什么：从模板生成真实配置文件。**这个文件包含你的个性化配置，永不入 Git**）

```bash
cd /opt/qimiao
cp .env.example .env
nano .env
```

在 nano 里确认/修改这几项（改完 `Ctrl+O` 保存、`Ctrl+X` 退出）：
- `MODULES_ENABLED=todo` —— 首版保持不动
- 其余站点信息按喜好改

## 第 5 步：启动站点

（做什么：构建镜像并后台启动。`-d` = 后台运行，`--build` = 先构建镜像）

```bash
cd /opt/qimiao
docker compose -f deploy/docker-compose.yml up -d --build
```

验证（做什么：确认容器活着、站点能响应）：

```bash
docker compose -f deploy/docker-compose.yml ps      # STATUS 应为 running
curl -s http://127.0.0.1:8000 | head -20            # 应输出首页 HTML
```

> 出问题时看日志：`docker compose -f deploy/docker-compose.yml logs -f`（Ctrl+C 退出）

## 第 6 步：Nginx 反向代理

（做什么：装 Nginx，把 80 端口的请求转发给容器。外界不直接接触 8000 端口）

```bash
dnf install -y nginx
cp /opt/qimiao/deploy/nginx/qimiao.conf /etc/nginx/conf.d/qimiao.conf
nano /etc/nginx/conf.d/qimiao.conf
```

把 `server_name your-domain.com;` 一行改成你的域名（没域名就填服务器公网 IP），保存退出。然后检查并重载：

```bash
nginx -t && systemctl reload nginx
```

此时浏览器访问 `http://你的域名或IP` 应该就能看到小站了。

## 第 7 步（有域名才做）：HTTPS

（做什么：用 certbot 申请 Let's Encrypt 免费证书，自动改写 Nginx 配置并配好续期）

```bash
dnf install -y certbot python3-certbot-nginx
certbot --nginx -d 你的域名
```

按提示输入邮箱、同意条款即可。验证自动续期（做什么：模拟续期流程，显示 success 就行）：

```bash
certbot renew --dry-run
```

## 第 8 步：收尾检查清单

- [ ] `http(s)://域名` 打开，首页正常显示
- [ ] 点导航「待办」→ 能添加、勾选、删除待办
- [ ] 手机访问布局正常（响应式）
- [ ] 访问一个不存在的路径（如 `/xxx`）→ 出现贴纸风 404 页
- [ ] `docker compose -f deploy/docker-compose.yml ps` 显示 running

---

## 常用速查

| 事项 | 命令 |
|---|---|
| 启动 | `cd /opt/qimiao && docker compose -f deploy/docker-compose.yml up -d` |
| 停止 | `cd /opt/qimiao && docker compose -f deploy/docker-compose.yml down` |
| 重启 | `cd /opt/qimiao && docker compose -f deploy/docker-compose.yml restart` |
| 看日志 | `docker compose -f deploy/docker-compose.yml logs -f` |
| 更新版本 | 见《日常维护手册.md》 |
| 回滚版本 | `bash scripts/rollback.sh` |

恭喜，上线了。日常更新/备份/回滚看《日常维护手册.md》。
